# GitHub Achievements Lab

A small, legitimate practice repository for learning real GitHub workflows: issues, branches, pull requests, and collaboration.

This project is intentionally simple. Every change should be meaningful and useful — not spam.

## What's in this repo

| File | Purpose |
|------|---------|
| `README.md` | Project overview and workflow notes |
| `checklists/workflow.md` | Short checklists for issues, PRs, and merges |
| `scripts/validate-checklist.ps1` | Lightweight validator for the checklist format |

## Legitimate workflows practiced here

1. **Issues** — open a clear, actionable improvement; close it when done.
2. **Feature branches** — isolate small changes, then open a pull request.
3. **Pull requests** — describe *why* the change helps, then merge when ready.
4. **Collaboration** — co-author commits only with real contributors who agree to participate.

## Ground rules

- No fake stars, fake users, or bot-driven activity.
- No spam issues, PRs, comments, or empty commits.
- Keep changes small but useful.
- Prefer clarity over volume.

## Quick start

```bash
# Clone (after the remote exists)
git clone https://github.com/<your-username>/github-achievements-lab.git
cd github-achievements-lab

# Validate checklist formatting (PowerShell)
pwsh ./scripts/validate-checklist.ps1
```
